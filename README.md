# AirTalk v0.1 — AirPods音声入出力検証

このZIPは、AirPods 4（ANCなし）で音声入出力を調べるための、最小限のiOSネイティブアプリです。

## v0.1で確認すること
- Bluetoothヘッドセットの入力・出力ルート名を表示
- AirPodsマイクからの入力レベルを表示
- マイク入力と音声出力を同時に動かす
- 440Hzの短いテスト音を出力する

## 重要な制約
この版は左右のマイクを独立取得するものではありません。iOSの公開APIからAirPods左右のマイクを個別に同時取得できる保証はありません。まず現在のiOSが選択した入力ルートと出力ルートを実機で確認します。

## GitHubへのアップロード
1. ZIPを展開する
2. 中身をGitHubリポジトリのルートにアップロードする（`.github` フォルダも含める）
3. `Actions` タブを開く
4. `Build AirTalk iOS` を実行、またはmain/masterへpushする
5. 成功したら `AirTalk-unsigned-build` をArtifactsから取得する

## iPhoneへのインストールについて
GitHub Actionsで作られる `.app` は署名なしです。そのままiPhoneへ通常インストールはできません。実機インストールにはAppleの署名・プロビジョニングが必要です。次の段階で、iPhoneだけで扱える配布・署名方法を検討します。

## 動作テスト
1. AirPodsをiPhoneに接続する
2. AirTalkを起動し「音声テストを開始」
3. マイク権限を許可
4. 接続状態の「入力」「出力」にAirPodsが表示されるか確認
5. 声を出して入力レベルが動くか確認
6. 音量を小さめにして「テスト音を再生」

※テスト音は短い440Hzの音です。耳を守るため、最初はiPhoneとAirPodsの音量を下げてください。
